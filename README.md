# Job Tracker

개발자 채용공고를 매일 모아 신규 공고, AI 관련 공고, 기술스택, 마감 임박 공고를 확인하는 개인 취업 대시보드입니다.

## 기술스택

- Next.js
- TypeScript
- Tailwind CSS
- App Router

## MVP 기능

- 메인 대시보드
- 전체/신규/AI 관련/마감 임박 통계 카드
- mock 데이터 기반 공고 카드 리스트
- 키워드, AI 관련, 신규 공고 필터
- 기술스택 태그와 관심 등록 버튼 UI

## 실행

```bash
npm install
npm run dev
```

## 향후 계획

- 사람인 등 채용 플랫폼 수집 연동
- Supabase 저장소 연동
- 관심 공고 저장과 지원 상태 관리
- 일일 요약, 마감 임박 알림, 자동 리포트
