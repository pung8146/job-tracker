# Job Tracker PRD

## 1. 목적

Job Tracker는 개발자 채용공고를 매일 모아 개인 취업 활동을 빠르게 점검하는 대시보드다. 초기 MVP는 실제 수집 연동 없이 mock 데이터를 사용해 제품 방향, 화면 구조, 핵심 필터 경험을 검증한다.

## 2. 문제

- 여러 채용 플랫폼을 매일 직접 확인해야 한다.
- 신규 공고, AI 관련 공고, 기술스택, 마감 임박 공고를 한 화면에서 비교하기 어렵다.
- 관심 공고를 따로 관리하기 번거롭다.

## 3. MVP 범위

- 메인 대시보드 1개 화면
- 통계 카드 4개: 전체 공고 수, 오늘 신규 공고 수, AI 관련 공고 수, 마감 임박 공고 수
- 공고 카드 리스트
- 키워드 선택, AI 관련 공고만 보기, 신규 공고만 보기 필터
- mockJobs 파일 기반 데이터 표시
- TypeScript 타입과 컴포넌트 분리

이번 단계에서는 사람인 API, 크롤링, Supabase, 로그인, 서버 저장 기능을 구현하지 않는다.

## 4. 공고 데이터

공고는 제목, 회사명, 출처, 지역, 경력, 고용형태, 마감일, 키워드, 기술스택, AI 관련 여부, 신규 여부를 가진다. MVP에서는 `src/data/mockJobs.ts`에 고정 데이터를 둔다.

## 5. 화면 구성

메인 페이지는 상단 요약 영역, 필터 영역, 공고 리스트 영역으로 나뉜다. 필터는 클라이언트 상태로 동작한다. 관심 등록 버튼은 UI만 제공하고 저장하지 않는다.

## 6. 향후 계획

- 사람인 등 채용 플랫폼 수집 연동
- 중복 공고 병합과 신규 공고 감지
- Supabase 저장소 연동
- 관심 공고 저장, 메모, 지원 상태 관리
- 알림, 이메일 요약, 자동 리포트
